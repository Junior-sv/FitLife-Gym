# FitLife Fitness Gym Website

## 1. Project Overview

FitLife Fitness Gym is a website created for a fitness gym organisation. The purpose of the website is to provide visitors with information about the gym, its services and how they can contact or make an enquiry with the gym.

The website was developed as part of a Web Development project.

## 2. Website Goals

The main goals of the website are to:

* Provide information about FitLife Fitness Gym.
* Display the services offered by the gym.
* Allow visitors to make enquiries.
* Provide contact information.
* Create a simple and user-friendly website.
* Make the website accessible on computers, tablets and mobile phones.

## 3. Website Pages

The website contains the following pages:

* **Home (`index.html`)** – Introduces FitLife Fitness Gym.
* **About (`about.html`)** – Provides information about the organisation.
* **Services (`services.html`)** – Shows the services offered by the gym.
* **Enquiry (`enquiry.html`)** – Allows visitors to submit an enquiry.
* **Contact (`contact.html`)** – Provides contact and location information.

## 4. Technologies Used

The following technologies were used to develop the website:

* **HTML5** – Used to create the structure and content of the web pages.
* **CSS3** – Used for styling, layout, colours, fonts and responsive design.
* **JavaScript** – Used where required for website functionality.
* **Visual Studio Code** – Used as the development environment.
* **GitHub** – Used to store and manage the project repository.

## 5. Responsive Design

The FitLife website has been designed to work on different screen sizes.

The website supports:

* Desktop computers
* Tablets
* Mobile phones

CSS media queries were used to change the layout and sizing of elements on smaller screens. Images are also responsive and automatically adjust to the available screen width.

The website was tested using different screen sizes to make sure that the content remains readable and usable.

## 7. How to View the Website

To view the website:

1. Download or clone the project from GitHub.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a web browser.
4. Use the navigation menu to visit the different pages.

## 8. GitHub

The FitLife Fitness Gym website is stored in a GitHub repository. GitHub is used to keep track of changes made to the project and to provide access to the completed website project.

## 9. Conclusion

The FitLife Fitness Gym website provides a simple and user-friendly way for visitors to learn about the gym, view its services and make enquiries. The website also uses responsive design so that it can be viewed on desktop computers, tablets and mobile phones.
